# YOLO 球定位初步划分 v1

仅使用 `data/pp_train_data`，未使用官方 public_data 的事件标注。154 段视频全部解码，实际尺寸、帧数、0 基帧号范围与 JSON 校验通过。视频与标注 SHA256 见 audit.json；逐样本原始球框、分辨率、视频、帧号见 train.jsonl / val.jsonl。

- train：3,162 张，目录 00、01、05–11、13–20、23、24；按原帧号每 5 帧采样，仅保留存在球框的帧。
- val：5,302 张，目录 02、03、04、12、21、22；保留全部存在球框的帧。
- 总帧数 23,690；其中 2,844 帧无球框，语义未知，排除出监督和精度统计。不得将其当成确定背景。
- 8 个选中球框超出边界，对其裁剪到真实图像边界；不丢弃小框。JPEG 保存质量 95；模型使用 letterbox，预测框自动映射回原图。

分组依据：人工查看各编号首段视频首帧的场景拼图 `out/yolo_setup/source_groups.jpg`。02/03/04 共享相似场馆，整体放入 val；06/07/08 共享粉色赛事场景、17/20 共享室内俱乐部场景，均整体放入 train。其余按整个目录保留。每段视频的首张有球样本叠框图位于 `out/datasets/yolo_ball_v1/label_previews/`。抽查 02_001 球框与球位置吻合。

**限制**：源文件没有原始长视频或比赛身份元数据，不能证明跨编号来源完全独立；本划分是保守场景分组的 pilot，不是已核验的独立测试集。val 用于选择最佳 checkpoint，禁止把该结果称为独立测试成绩。连续漏检只统计逐帧有标注的连续区间，未知帧处断开。
