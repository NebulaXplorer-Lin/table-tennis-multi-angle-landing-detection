# 球桌 baseline 对照与问题诊断（2026-11-04）

结论：新B共享分支尚未达到旧baseline；退化幅度需要按相同均值口径比较。现有证据更指向新桌框头的全局信息利用、回归读出与薄框覆盖不足，不能据此判定B球定位器本身更差。本次只读诊断，没有更新权重、修改运行中的训练配置或启动额外训练。

## 1. 同标签、同评分口径

旧模型保留原checkpoint和原预测，将5101个有效验证帧统一用`pp_table_reannotated_v1`标签重算。40个验证视频均保留推理身份，视频均值仅聚合其中39个存在有效桌框GT的视频；新旧一致。

| 模型 | 帧均IoU | 视频均IoU | 依据 |
| --- | ---: | ---: | --- |
| 旧Global＋4×4池化＋MLP，旧标签 | 38.75% | 32.27% | 历史全量审计 |
| 同一个旧模型，修订v1标签 | 38.76% | 32.29% | 本次重评分，未重训 |
| B Global＋新中心热图/密集框头，第11轮best | 31.49% | 29.71% | 第23轮早停后的best完整评估 |

相同口径，新B帧均落后约**7.27个百分点**，视频均落后约**2.58个百分点**。原来38.75与29.71相减会混入帧均/视频均的差异。六帧修订对旧成绩的影响很小，不能解释本轮退化。旧baseline本来就有跨场景、薄框质量问题，也不是理想目标。IoU≥0.5比例由38.01%降至19.68%。

新B第23轮触发既定早停后，best的全量指标已写出，错误叠图仍可能在收尾；以下均为相同v1有效验证帧的帧均IoU：

| 分层 | 帧数 | 旧baseline | 新B |
| --- | ---: | ---: | ---: |
| 正视 | 628 | 28.77% | 54.83% |
| 斜视 | 2118 | 35.58% | 38.75% |
| 侧视 | 2355 | 44.28% | 18.73% |
| 薄框子集 | 629 | 21.79% | 8.64% |

侧视2355帧及薄框629帧中，新B均没有IoU≥0.5的预测。薄框的成功预测下边界误差中位为150.81原图像素，约4.88倍GT框高，表明框过高/向下偏移十分严重。106/5101帧完全无预测（2.08%），整体问题不能仅用漏检率或降低分数阈值解释。

固定新B第11轮best，用CPU FP32进行只读前向：每个训练视频抽一帧，共114帧；每个有GT的验证视频抽三帧，共117帧。旧模型在完全相同的帧上读取原缓存/原预测。该抽样按视频平衡，不代表全量帧平均成绩；以下GT中心读出仅为诊断，不是合法推理或性能上限。

| 相同抽样 | 旧baseline | 新B实际推理 | 新B改在GT中心读取框（诊断） |
| --- | ---: | ---: | ---: |
| train，114帧 | 69.20% | 36.76% | 48.70% |
| val，117帧 | 32.10% | 30.09% | 27.55% |
| val正视，24帧 | 28.55% | 54.18% | 48.37% |
| val侧视，51帧 | 27.23% | 12.13% | 15.56% |

训练侧新模型也明显落后，不能只解释为验证过拟合。验证不是所有视角都差，主要损失出现在侧视/薄框。把热图中心替换成GT中心没有整体救回验证框，说明框回归本身也存在问题，而非只有选点错误。

## 3. 已确认的实现差异与可能原因

### 新头缺少显式全图空间聚合

旧头把整幅32通道空间图池化为4×4，MLP同时读取16个位置，回归一个全局bbox，约66,180参数。新头仅新增3×3卷积，再以1×1输出中心和四个绝对归一化坐标，合计9,445参数；推理只在热图最大位置读一次框。上游FPN有上下文，但新桌框头没有显式汇聚整个球台的空间布局，也没有坐标通道。

这是本轮需要优先修正的设计假设：保留大空间图不自动等于更好利用全局几何。新头还要从某个局部位置推断整张球台的绝对边界，任务比旧全局读出更脆弱。当前样本显示边界偏移、框过高以及置信度拒绝，尤其伤害薄台面。该解释仍需固定B编码器的旧头/新头配对实验验证，不能单凭本轮确认因果。

### 回归仅监督GT中心，推理读取预测中心

`SharedGlobalTableHead.loss`只在整数GT中心格点上监督bbox；其他点只有中心热图监督。推理在预测热图的argmax读取bbox，两者位置可能差很多。验证抽样的中心误差中位约39.31个输入像素；薄框的纵向中心误差中位达到1.34倍GT框高。

这一错位会增加不稳定性，但GT中心诊断的验证IoU仍低，不能把全部问题归为中心定位。应同时处理全局读出/坐标表示及回归监督覆盖。

### B编码器仍冻结，球桌监督没有改善视觉特征

当前B只训练新桌框头，球定位Global完全冻结。B的球定位改善不等于桌面边缘特征改善。本轮同时改变了球编码器来源和桌框头，缺少“同一个B＋旧MLP”的控制，因此还无法区分两者的影响。独立CNN能够通过桌框监督更新编码器，但仍复用了相同的中心/框读出，不能预先保证它会解决全部问题。

### 薄框增采的实际效果不足

扫描前22轮训练清单，共88,000次曝光、17,153个唯一中心帧；薄框曝光只有**2.96%**（每轮103–137/4000）。原训练分布为2.78%，验证为12.33%。即便配置`thin_weight=3`，目前按场景/视频分配和循环队列得到的实际曝光仍接近原分布，不能当作薄框覆盖已经补齐。

### 损失尺度和多个变量同时变化

抽样训练分项为center约2.66、L1约0.052、GIoU约0.55。中心项按空间像素求和，L1和GIoU按元素/样本均值计算，三项直接相加；这提示需要检查梯度尺度，而不是以总loss下降代替边界质量改善。数值占比不能直接证明梯度占比。

此外，新头lr=1e-3、effective batch16、每轮4000张并加仿射增强；旧头lr=3e-4、batch128、每轮全部有效帧、无在线增强。不能以epoch或两者总loss直接横比，也不能把退化只归因于某一个因素。

## 4. 建议修正顺序

1. **补B＋旧MLP控制。** 固定同一个B编码器、v1标签与评价口径，用旧式全图4×4读出隔离编码器与新头的影响；原旧MLP权重不能跨Global SHA直接移接，需要在B特征上训练匹配头。
2. **增强轻量CNN的全局读出。** 优先加入明确的全图/多尺度空间汇聚，或将局部框表示改为相对中心的边界距离，并在中心邻域监督回归，降低单格点读出的错位风险。保留桌面空间描述符供事件融合，不必为了输出描述符强迫bbox只由局部点预测。
3. **按实际曝光验收采样。** 明确薄框桶配额、场景和视频上限，记录真实曝光比例、重复与独立场景覆盖；不只检查`thin_weight`参数值。
4. **分别记录中心/边界损失与梯度。** 先固定增强、batch和训练曝光，再比较读出结构；少量解冻B应后置并保留球定位辅助损失。

运行中的B按原计划继续，本诊断不改变当前训练队列或混入新配方。下一轮应使用新实验目录；当前结果作为明确的负结果保留。
