两条CNN路线未超过旧baseline；随后已完成[旧Global/B Global＋相同MLP配对对照](B_legacy_mlp_control_20261104.md)，固定初始化、样本顺序及旧MLP配方。B＋MLP验证帧均/视频均IoU为46.37%/36.18%，高于配对旧Global的39.40%/30.59%，表明B特征能够支持更好的整体桌框预测，优先检查CNN头与配方组合。B＋MLP薄框仅6.36%、斜视29.21%，仍明显退化；下一轮优先控制采样与薄框/源组覆盖，逐视频和分桶共同验收。事件头训练继续等待合格前端。

用户随后批准合并三项改进并重训：[B＋MLP薄框改进](B_mlp_thin_20261104.md)已完成（22轮早停、best第12轮），合并16×4池化、约10%薄框实际曝光（每帧最多4次、每视频约30%薄框槽位上限）、相对纵向中心及对数高度损失。验证帧均/视频均IoU为48.25%/37.19%，薄框从6.36%升至23.53%、中心相对误差从1.690降至0.718；但正视66.34%→50.85%，整体IoU≥0.5比例56.85%→45.62%，薄框IoU≥0.5仍为0。两版权重并存，下一步先控制正视退化与薄框高度膨胀，不直接替换事件前端。此轮为组合配方比较，不作为三个独立消融。

按用户要求完成了[独立特征编码器＋MLP与调色增强](independent_mlp_color_20261104.md)：原生CNN/FPN输出32通道空间图后接16×4池化MLP，编码器和头从头联合训练，加入亮度、对比度、饱和度、色相及几何增强。每轮4,096次曝光、batch16完整整除、约10%薄框，按视频均IoU选主best并另存帧均/薄框best。第11轮早停、best第1轮，验证帧均/视频均41.86%/42.89%，薄框43.24%、薄框IoU≥0.5为13.04%；但总体IoU≥0.5仅18.11%，组22退至36.36%。新路线改善薄框与视频均，仍有明确场景取舍，保留对照而不直接替换事件前端。

最新按用户要求完成[YOLO11s原生配方对照](yolo_table_native_20261104.md)：本地COCO预训练、原生DetectionTrainer与检测损失、HSV/Mosaic，640输入，全量17,281个已知框训练帧/轮，24轮早停、按原生mAP50–95选主best为第12轮。使用同版114/40划分，unknown排除训练/AP；已完成全量train/val评分和错误叠图，验证帧均/视频均/薄框IoU为54.73%/71.08%/70.65%，IoU≥0.5比例67.28%。但组22漏检1,652/1,726帧、组均IoU仅3.53%，应优先核查该组候选置信度和场景差异，不能只看视频宏平均。该轮与MLP的预训练、增强和曝光预算均有变化，属于整套配方比较；事件头仍未启动，尚未切换前端或调整阈值。

## 起点与边界

保留三种子完整的[TCN+桌框+时间编码](../result/tcn_frames_lr0.0003_d0.1/README.md)作为主基线；[EMA候选](../result/20261017-112200_tcn_fast_refine/README.md)只有seed42，内部少1个FP，外测相同。现阶段没有足够证据证明EMA有稳定精度收益。

固定PP 114/40视频及源场景隔离；PP public和OpenTTGames test仅用于锁定后的外测。当前三帧定位、13原生帧事件窗、规则关联和TCN可复用。后续不恢复已停止的全随机联合训练；其初始化与训练范围同时变化，且没有完成验证。

2026-11-03用户决定：小范围标注问题先暂缓处理。后续桌框实验使用已发布的`pp_table_reannotated_v1`，unknown继续mask；训练集细微边界和零星缺标精修不再作为训练前置条件。优先推进独立桌框视觉分支，结合完整验证与错误分析再决定是否重启标签精修。

| P2 冻结事件头 | 固定前端，用预测轨迹/桌框提特征；先建立简单拼接TCN基线 | 缓存身份与在线结果抽查一致；固定40视频完整评分；与当前基线可配对比较 |
| P2 消融 | 分别测试桌面视觉、门控融合、前后状态读出、PP粗时刻软目标 | 一次只改变一类因素；小收益补42/43/44配对种子，逐视角无明显退化 |

## 优先解决的问题

1. 桌框旧头训练/验证IoU为72.21%/38.75%，薄框分布不均；`04_004:115–120`六帧已重标并发布[独立修订v1](table_reannotation_20261103.md)，均在val。新增[训练专项核查](train_table_audit_20261103.md)确认`14_002:56–57`边界错误、`13_001:120`和`13_006:17`可见台面缺标，按用户决定暂缓修订并保留清单，不阻塞下一阶段训练。历史[标签时间审计](table_label_temporal_20261018.md)保留，后续模型比较统一使用同版标签；镜头变化不能用整段固定框自动覆盖。
2. 主基线45个FN里38个在GT邻域已有50px内球坐标，提示事件判别值得改进；这是GT诊断，不能用作推理上限或输入特征。
3. 当前AR配方和困难背景采样已有完整负结果。暂不扩大AR beam、更大Transformer或复跑同一退化配方；这些结论只约束已有设置。
4. 新桌框要保留空间视觉描述符，先简单拼接，再测试复杂融合。桌框bbox四角不能当作真实桌面四角求单应。

具体候选及约束见[桌框改进](table_localization_improvement_20261018.md)、[事件头改进](event_head_improvement_20261018.md)、[训练白皮书](training_whitepaper_20261018.md)。文中的YOLO11s等为待验证起点，骨干与具体超参尚未锁定。

## 机器、排期与验收

服务器只有100GB总磁盘，使用[原视频按需解码方案](server_100gb_20261018.md)，关闭Global缩放图和Local裁剪图的磁盘缓存，保留有界内存读取与小型冻结特征。旧233GiB缓存迁移方案及6–13小时预算只作历史参考，上机测数据等待、训练/验证全流程后重排时间。

两张卡可分配互不依赖的单卡作业；现有训练不默认支持DDP。优先做前后向、标签叠图、恢复、真实完整视频预检，之后才完整训练。独立桌框训练可以与球定位并行，冻结特征必须等待最终前端锁定。

选型固定原帧±1、原图50px、一对一匹配、三视角宏F1，单独报告球定位与稀疏分类；保留所有错误覆盖。部署吞吐目标≥50 FPS，初始化、写盘及6+1帧前瞻分别列出。研究模型接入赛事仍是一项待完成工作。
