# 当前研发路线

更新：2026-10-20。本文维护下一步决策；已有实验与模型先读 [Quick intro](quick_intro.md)，实际运行见[训练指南](training_guide.md)。

## 起点与边界

保留三种子完整的[TCN+桌框+时间编码](../result/tcn_frames_lr0.0003_d0.1/README.md)作为主基线；[EMA候选](../result/20261017-112200_tcn_fast_refine/README.md)只有seed42，内部少1个FP，外测相同。现阶段没有足够证据证明EMA有稳定精度收益。

固定PP 114/40视频及源场景隔离；PP public和OpenTTGames test仅用于锁定后的外测。当前三帧定位、13原生帧事件窗、规则关联和TCN可复用。后续不恢复已停止的全随机联合训练；其初始化与训练范围同时变化，且没有完成验证。

## 三阶段主线

| 优先级 | 工作 | 完成条件与下一步 |
| --- | --- | --- |
| P0 数据 | 复核桌框错标、薄框、镜头变化、缺框；冻结修订版本 | 原值/新值/原因/审核人、划分哈希、GT叠图齐全；旧头和新头在同版标签下比较 |
| P1 前端 | 复用或重训合格Global/Local；实现独立单帧桌框编码器，以桌框预测辅助任务监督特征 | 球定位完整视频评分；桌框整体/逐视频/三视角/薄框指标与错误视频；球与桌框特征接口确定 |
| P2 冻结事件头 | 固定前端，用预测轨迹/桌框提特征；先建立简单拼接TCN基线 | 缓存身份与在线结果抽查一致；固定40视频完整评分；与当前基线可配对比较 |
| P2 消融 | 分别测试桌面视觉、门控融合、前后状态读出、PP粗时刻软目标 | 一次只改变一类因素；小收益补42/43/44配对种子，逐视角无明显退化 |
| P3 少量FT | 从合格前端/事件头初始化，仅从原训练集选少量数据，在线重算可求导特征，保留定位和桌框辅助损失 | 参数更新/恢复证据、与冻结版配对评估、回退权重；不能使用冻结特征假装更新编码器 |
| P4 发布 | 锁定内部配置后外测；接入赛事participant并导出、测速 | 完整输出与错误索引、固定比赛镜像数值一致性、完整≥50 FPS，未来帧等待另报 |

独立桌框编码器、新桌面ROI特征接口、融合门控和少量FT子集路径尚待实现。现有`event_tcn_reference.json`与`server/event_reference.json`都仍是旧桌框参考；`events/joint.py`有在线联合训练基础，但不能直接充当新分支训练方案。

## 优先解决的问题

1. 桌框旧头训练/验证IoU为72.21%/38.75%，薄框分布不均；`04_004:115–120`疑似错标，先看[标签时间审计](table_label_temporal_20261018.md)。镜头变化不能用整段固定框自动覆盖。
2. 主基线45个FN里38个在GT邻域已有50px内球坐标，提示事件判别值得改进；这是GT诊断，不能用作推理上限或输入特征。
3. 当前AR配方和困难背景采样已有完整负结果。暂不扩大AR beam、更大Transformer或复跑同一退化配方；这些结论只约束已有设置。
4. 新桌框要保留空间视觉描述符，先简单拼接，再测试复杂融合。桌框bbox四角不能当作真实桌面四角求单应。

具体候选及约束见[桌框改进](table_localization_improvement_20261018.md)、[事件头改进](event_head_improvement_20261018.md)、[训练白皮书](training_whitepaper_20261018.md)。文中的YOLO11s等为待验证起点，骨干与具体超参尚未锁定。

## 机器、排期与验收

服务器只有100GB总磁盘，使用[原视频按需解码方案](server_100gb_20261018.md)，关闭Global缩放图和Local裁剪图的磁盘缓存，保留有界内存读取与小型冻结特征。旧233GiB缓存迁移方案及6–13小时预算只作历史参考，上机测数据等待、训练/验证全流程后重排时间。

两张卡可分配互不依赖的单卡作业；现有训练不默认支持DDP。优先做前后向、标签叠图、恢复、真实完整视频预检，之后才完整训练。独立桌框训练可以与球定位并行，冻结特征必须等待最终前端锁定。

选型固定原帧±1、原图50px、一对一匹配、三视角宏F1，单独报告球定位与稀疏分类；保留所有错误覆盖。部署吞吐目标≥50 FPS，初始化、写盘及6+1帧前瞻分别列出。研究模型接入赛事仍是一项待完成工作。
