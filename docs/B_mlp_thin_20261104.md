# B＋MLP薄框改进训练

## 本轮改动

| 项目 | 上轮B＋MLP | 本轮 |
| --- | --- | --- |
| 空间池化 | 32×4×4，512维 | 32×16×4，2048维，重新提取冻结B特征 |
| 桌框MLP | 512→128→4 | 2048→128→4，262,788参数；仍使用SiLU和Sigmoid有序四角 |
| 薄框曝光 | 全量有效帧均匀曝光，480/17,281（2.78%） | 每轮固定1,728/17,281（约10%）薄框；单薄框最多4次，单视频最多占薄框曝光30% |
| 基础损失 | L1＋GIoU | 保留基础损失，另加0.25×相对纵向中心SmoothL1和0.25×对数高度SmoothL1 |

薄框按GT高度/原图高度<0.06定义，仅用训练侧GT划分采样桶。薄框队列先轮转视频，每视频内打乱完整帧序列后再重复；单视频槽位上限按`ceil(1728×0.3)=519`取整。普通框从普通桶无放回选择，不改变每轮17,281次训练曝光及136次优化步数。每轮保存完整抽样序列、唯一帧/视频数、分源组和分视频曝光、最大重复次数及序列hash；如果配额与重复上限不兼容则直接报错，不静默降低配额。

纵向中心误差为 `(cy_pred-cy_gt)/max(h_gt,0.02)`，坐标均归一化到512×288输入；归一化因子最多50，SmoothL1的beta=1。高度项对 `log(max(h_pred,1e-4))-log(max(h_gt,1e-4))` 求SmoothL1。所有有效框均参与上述损失，unknown保持屏蔽；不使用验证标签训练。

## 固定条件与边界

- B Global沿用混合球best（SHA `04e2bdc4c50b15e40d663fc6170f6902a6ffda806a05a74554d88a4aaf7f865a`），eval且完全冻结；三帧输入和真实时间偏移沿用。
- 标签为`pp_table_reannotated_v1`，固定114/40视频划分；训练17,281个有效框、验证5,101个有效框。
- MLP从头初始化seed42；AdamW lr=3e-4、weight decay=1e-4、batch128、无在线增强、最多60轮、patience10，按验证帧均IoU选best。
- 对照为[上一轮B＋4×4 MLP](B_legacy_mlp_control_20261104.md)：验证帧均46.37%、视频均36.18%、薄框6.36%。新验证key与target必须逐行等于该对照，权重和标签身份必须相同。
- 同时记录逐轮视频均/薄框IoU，以及中心位移/框高、预测与真实高度比、上下边界相对框高误差；最终保存train/val完整分视角/源组/视频指标、逐帧预测、错误索引和逐视频最差叠图。
- `TableHead`及冻结特征提取支持显式pool尺寸，默认4×4；事件系统和AR准备入口按checkpoint的`table_pool`加载，防止16×4权重被当成旧512维头。低分辨率缓存不能通过上采样冒充16×4特征。本轮不启动事件训练，也不追加单元测试。

三项按用户要求合并，因此结果只能评价组合配方，不能分别归因。当前训练薄框480帧中478帧仍来自源组13；采样只能增加曝光，不能制造独立场景覆盖。后续如需补样本，应保持验证隔离，在原训练划分内补充更多场景的真实薄台面。

22轮每轮实际薄框曝光均为1,728/17,281（9.9994%），覆盖全部480个薄框、8个视频，最大单帧重复4次。首轮两个最大薄框视频各482次曝光，均低于519次槽位上限；源组13仍占1,720/1,728次曝光，因此场景覆盖限制保持存在。

薄框均IoU提升17.18个百分点，略超过历史旧baseline按v1重评的21.79%；主要改善是中心下偏减轻，框高膨胀仍接近两倍，尚无薄框达到IoU≥0.5。整体帧均/视频均提高1.89/1.01个百分点，但正视下降15.48个百分点、整体IoU≥0.5比例下降11.23个百分点；本轮存在明确取舍，不能直接宣布新前端全面替代旧模型。

下一步应保留两版权重，以本轮完整分桶结果确定正视保护和薄框高度约束方案；如继续训练，需单独比较采样/纵向损失权重或结构因素，固定其它条件，不能把这次组合结果拆成单因素结论。本任务到训练评估归档结束，未额外启动其它训练或事件头。
