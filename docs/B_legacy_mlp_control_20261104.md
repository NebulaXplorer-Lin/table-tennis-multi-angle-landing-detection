# 冻结Global＋旧MLP配对对照

2026-11-04用户批准执行“B＋旧MLP”对照。任务：[实时状态](../out/experiments/20261104-142741_B_legacy_mlp_control/task.json) · [日志](../out/launches/20261104-142741_B_legacy_mlp_control/driver.log) · [执行代码](../ttnet/src/scene/table_mlp_control.py)。

## 两个配对分支

- `reference`：旧Global权重，复用历史32×4×4空间缓存，按修订v1重新编码targets；重新训练MLP，不直接拿历史best作唯一参考。
- `B`：混合球训练的B Global，重新提取同样的32×4×4空间特征；重新训练同结构MLP。

两种Global均冻结，只有桌框头更新。MLP结构均为全图4×4池化、展平512、Linear512→128、SiLU、Linear128→4、Sigmoid及坐标顺序约束，共66,180参数。

## 固定条件

| 项目 | 设置 |
| --- | --- |
| 标签/划分 | pp_table_reannotated_v1，114训练/40验证视频；unknown屏蔽 |
| 初始化 | 同一个seed42新MLP初始state，保存初始权重摘要 |
| 训练数据 | 全部17,281个有效训练框；无在线增强、无薄框重采样 |
| 采样 | 两分支每轮完全相同的排列，保存排列hash；逐行校验输入key和target相等 |
| 优化 | AdamW，lr=3e-4，weight decay=1e-4，batch128，L1＋GIoU |
| 时长/选型 | 最多60轮，patience10，按验证帧均IoU选best；同时记录视频均IoU |
| 特征 | Global原三帧与真实时间偏移；512×288；AMP提特征后存FP32，MLP用FP32训练 |

旧缓存只读，派生缓存与新B缓存写在本任务目录。两分支保存独立best/last、优化器、历史、逐帧验证框、各视角/源组/薄框指标及逐视频错误示例。没有追加单元测试，没有启动事件头训练。

## 能回答的问题

成对MLP的差异主要反映冻结Global特征的差异；相同初始化和顺序减少一次训练噪声，但单seed结果不等同于多seed稳定结论。

本次使用旧MLP训练配方。它与此前B中心热图/CNN头的4000张/轮、增强、batch16、lr=1e-3及视频均选型不同，因此两者结果差异仍包含配方影响，不能单独宣称为纯头结构因果。若B＋MLP恢复旧水平，则优先修正新CNN头与配方组合；若同配方下B＋MLP也明显更差，再检查冻结球特征的桌面表达。

## 完成结果

2026-11-04 14:34完成。两个分支的训练样本key、target逐行一致性检查通过；验证统一为v1的5,101个有效框、39个有GT视频。reference训练17轮早停、best第7轮；B训练至60轮上限、best第52轮。两组均已保存best/last、完整指标、逐帧预测及39张逐视频最差样例。

同配方结果表明，B冻结特征可以支持更好的整体桌框预测；此前整体退化不能仅归因于B编码器，应优先检查CNN头与训练配方组合。但B＋MLP对斜视和薄框仍有明显退化，薄框IoU≥0.5仍为0；源组21为16.86%、源组04为6.07%，整体提升并不均匀。B训练/验证仍相差35.08个百分点，后期验证波动明显，且本轮只有seed42，尚不能锁定为事件前端。

下一轮优先：核对实际薄框/源组采样覆盖；沿用B＋全图读出作为可追溯起点，固定其它条件单独比较按视频/源组均衡采样或薄框训练权重；将验证视频均、各视角及薄框作为共同准入依据。若研究CNN结构，再固定本轮MLP配方进行头结构对照，避免同时修改优化与采样。本次到配对实验及归档结束，没有追加事件训练或其它新训练。
