# 桌框标签随时间变化检查（2026-10-18）

结论：**label的精确坐标经常变化，多数片段近似静态，但有镜头变化和明确错标，不能整段无条件固定一个框。独立单帧桌框/场景分支是合理的优先候选。**

本次遍历全部154段PP原始标注，153段有有效桌框，共22382帧；02_002整段没有table标签。缺失的1308帧不插值、不当无桌背景。未修改标签、数据划分或训练模型。

## 1. 变化量有多大

对每个视频，以其所有已知GT框的逐坐标中位数为固定参考，衡量逐帧GT与该参考的IoU。参考由GT生成，**仅用于标签稳定性诊断，不是模型精度或可部署推理方案**。

| 统计 | 全部有标签视频 | 训练 | 验证 |
|---|---:|---:|---:|
| 视频数 | 153 | 114 | 39 |
| 静态参考平均IoU≥0.95 | 125 / 153（81.7%） | 98 / 114 | 27 / 39 |
| 静态参考平均IoU≥0.90 | 133 / 153（86.9%） | 104 / 114 | 29 / 39 |
| 至少95%已知帧的静态参考IoU≥0.90 | 119 / 153 | 95 / 114 | 24 / 39 |

视频级静态参考平均IoU的中位数为 **0.9892**。但均值会掩盖短暂镜头变化，例如08_004大部分已知标签来自全景，其整段平均值仍较高，开头近景却不能复用同一个框。

22106对相邻且均有标签的帧中，只有19.92%的框四坐标完全相同，即约80.08%至少有一个坐标变化。将像素距离统一换算为1080p（乘1080/原图高度），相邻帧四条边最大变化的中位数为 **0.75px**，P90为7.5px，P95为14.62px，P99为49.46px。这些是全部片段混合的分布，不能把尾部异常称作普遍小抖动。

- **04_004，第115帧**：原table框为`[0, 455.5, 286.25, 720]`，落在画面左下地板，球台仍位于画面中部。此帧属于明确的桌框标注异常。[35/115/195帧对照](../out/results/20261018_table_label_temporal/examples/04_004.jpg)

这会影响原始标签上的桌框IoU解释。原38.75%成绩保留，但不能将每个低IoU样本都认定为模型错位；清理应形成独立标签版本，并在同版标签上重新评估所有相关模型，不能只修正对某一模型不利的样本。

## 3. 对独立分支的建议

采用独立的单帧视觉网络，负责桌框定位和可选桌面/场景描述符，不再依赖球定位器的冻结特征。定位头保持空间分辨率，生成框后再池化事件所需的描述符。

“单帧输入”和“整段只算一次”是不同选择：

1. 输入只需当前RGB，不要求桌框网络使用球定位的相邻三帧。
2. 同一稳定镜头内用若干可信观测形成稳定框/场景表示，再低频更新。
3. 镜头切换、明显平移/缩放、质量下降或历史过期时重新定位。
4. 训练可按视频/镜头分配采样预算，减少近重复帧，保留遮挡、薄框、镜头变化与其他困难例。
5. 先学习可靠单帧定位，再加入一致性正则/聚合。时序一致性只施加在同镜头且质量可信的片段，不跨切镜头强行一致，也不先用中位数覆盖原始label。

具体骨干与输入尺寸仍需受控验证；用户本轮提出的是候选方向，尚未启动实现或训练。已确定的三阶段流程保持：定位/特征提取 → 冻结前端训练事件头 → 少量训练数据端到端FT。
