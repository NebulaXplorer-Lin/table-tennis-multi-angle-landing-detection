## 覆盖与读图方式

- 使用原固定 114/40 视频划分，覆盖全部 154 视频、25 个源场景组，共 662 个代表帧。抽取首/中/尾帧、有标注的代表帧、相对中位框偏离最大的帧，以及部分缺标帧；不是全部 23,690 帧的人工审核。
- 图册支持切换视频/代表帧、开关原框、100%–250% 放大，显示原始分辨率、原帧号、真实 PTS 与原图 xyxy。也可用左右方向键切帧。
- 绿色为原始桌框；04_004 第 115–120 帧的原始异常框用橙色显示。无标签明确显示 UNKNOWN。
- 每个视频有全图与局部上下文对照。局部裁剪参考同视频的框分布，只改变查看范围，不绘制中位框、不填补标签。
- 04_004 额外保留全部 196 帧叠图视频，使用原始 PTS 编码，不将其当作 25 FPS 视频。

这六帧在原验证集，错误标签直接影响桌框验证 IoU 的解释；本次没有重算原模型分数。已登记到[待重标清单](../out/results/20261103_table_label_review/confirmed_issues.json)，保留原值和来源哈希。

25 组代表图中，原框总体包围**桌面及桌沿**，基本不包含桌腿和底座；侧视时自然呈很薄的横框。斜视桌面是四边形，轴对齐 bbox 内会包含背景，不能把 bbox 四角当成真实桌面角点，也不能将框内全部像素视作桌面。代表图支持这一观察，但不证明全部原框符合统一边界规范。

## 修订顺序

1. 按主比赛球台的桌面与桌沿口径，对上述六帧重新标框；遮挡时结合相邻画面复核，但不复制整段固定框。
2. 继续核查薄框、遮挡、近景与切镜头边界；缺框保持 UNKNOWN，真实构图变化保留。
3. 形成独立修订版本，保留原值、新值、原因与审核信息；同版标签下重评旧模型和新模型。

本页记录最初的叠图和异常确认；随后已发布独立的 `pp_table_reannotated_v1`，详见[修订说明](table_reannotation_20261103.md)。原始 JSON、旧数据描述、帧缓存和 train/val 清单继续保留。

## 复现与来源

```bash
.venv/bin/python scripts/review_table_labels.py \
  --output out/results/<新的复核目录>
```
