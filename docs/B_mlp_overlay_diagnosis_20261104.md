# B＋MLP新旧叠图诊断（2026-11-04）

结论：本轮薄框改进主要来自纵向位置上移，薄框高度仍约为GT两倍；正视出现整体下移和右侧外扩，组03漏左侧台面，组21仍上偏且框高不足。偏差具有明确场景差异，当前组合不能直接替换原B＋MLP。另有最后一批仅1帧的优化问题，需要优先单独处理。

## 误差分解：纵向仍是薄框瓶颈

以下仅将某一项预测坐标临时替换为GT后重算几何IoU，使用GT进行诊断，不能用于实际推理，也不等同于可实现性能上限。

| 新模型诊断 | 薄框均IoU | 正视均IoU |
| --- | ---: | ---: |
| 实际预测 | 23.53% | 50.85% |
| 仅修正左右边界 | 29.12% | 59.25% |
| 仅修正上下边界 | 75.26% | 81.47% |
| 只把纵向中心移到GT，保留预测高度 | 41.56% | 69.68% |
| 只把高度改为GT，保留预测中心 | 22.14% | 52.49% |

薄框应同时改善位置与高度；固定中心直接缩框可能进一步失去交叠。正视主要需要纠正中心偏置，其次是横向读出。

## 整体指标为何看起来改善

原本IoU≥0.5、现在跌破的有586帧，反向提升到0.5的仅13帧；其中正视损失326帧、组03损失214帧，合计占全部下降帧的92.15%。因此均IoU上升与通过0.5的比例下降可以同时发生。

按固定5,101帧计算，组21对整体均IoU贡献+2.99个百分点、组04贡献+2.05个百分点；正视组12为−1.91个百分点、组03为−0.94个百分点、组22为−0.37个百分点，组02约+0.07个百分点，合计为+1.89个百分点。主要是较差场景获得部分改善，同时部分原本较好的场景退化。

训练薄框IoU为65.62%，验证23.53%。训练叠图13_004:43和13_007:113已能覆盖大部分台面，验证场馆04仍有显著下偏。薄框曝光配额确已生效，但1,728次中1,720次仍来自源组13，未增加独立场景多样性。这支持继续关注跨场景泛化；单次实验不能确定特征、采样与损失各自的因果贡献。

## 训练与选型问题

1. **最后一批只有1帧。** 17,281个样本按128直接split，得到135个满批和1个单样本批；该帧独占一次AdamW更新，随后立即验证。新实验第18/19轮帧均IoU为46.66%/35.77%，存在明显波动。最后小批次可能放大波动，尚未通过单因素对照证实。
2. **不同选型目标存在取舍。** 当前best为第12轮，帧均48.25%、视频均37.19%、薄框23.53%；第11轮视频均更高（39.56%）、薄框32.14%，但帧均40.85%。第2轮薄框35.82%，但帧均35.38%。这些epoch的逐轮指标可以查看，未保存其全部权重，不能把历史数字当成新的可交付checkpoint。
3. **相机稳定时仍有框抖动，但本轮主要是系统偏置。** 正视GT边界在视频内基本稳定，边界标准差通常不足1原图像素，新模型边界仍有约8–12像素波动；新模型平均波动没有高于旧模型，不能将退化简单归结为抖动增加。

建议下一轮先只修批次：将同样17,281个样本等分为136批，每批127–128个，保持曝光和更新步数，避免最后1帧更新；记录多项选型checkpoint及分桶指标。随后固定批次和结构，分别消融采样比例、中心损失与高度损失权重。若仍存在场景互相牺牲，再考虑保留4×4全局几何读出、将高纵向分辨率用于边界残差，并由预测信息决定适用范围。当前不追加训练或修改原权重。
