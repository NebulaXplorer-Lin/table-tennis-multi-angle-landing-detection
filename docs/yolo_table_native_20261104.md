## 实验内容

使用本地COCO预训练YOLO11s，全模型微调为`main_table`单类别检测，约943万参数。固定本地Ultralytics 8.3.225；权重`out/yolo_setup/weights/yolo11s.pt`的SHA256为`85a76fe86dd8afe384648546b56a7a78580c7cb7b404fc595f97969322d502d5`，不重新下载依赖或权重。实际日志已确认493/499项预训练参数匹配。

本次使用Ultralytics原生DetectionTrainer、检测头、box/cls/DFL损失、EMA、warmup和cosine调度。只替换数据读取接口，从既有FrameStore读RGB后按原生约定转BGR，原生Format再输出RGB张量；图像与标签一起经过原生增强。每图可有多个候选框，统一评价时按现有确定性规则选一个主桌框。

| 配方项 | 设置 |
| --- | --- |
| 输入 | 640×640，保持比例、居中补114灰边；RGB/255 |
| 优化 | AdamW，lr0=0.001，lrf=0.01，weight_decay=0.0005 |
| 批次 | batch8，nbs16，原生梯度累计与3轮warmup，AMP，2个数据worker |
| 轮数 | 最多60轮，patience12，seed42 |
| 检测损失 | box=7.5，cls=0.5，DFL=1.5 |
| 调色 | 原生HSV：h=0.015，s=0.7，v=0.4 |
| 几何 | 水平翻转0.5，平移0.1，scale=0.5，无旋转/垂直翻转/透视 |
| Mosaic | 概率0.5，最后10轮关闭；MixUp、CutMix关闭 |
| 主best | 原生mAP50–95，保存EMA权重 |

未运行额外单元测试。关闭原生AMP下载检查及外部训练平台集成，使用本会话已有的CUDA AMP环境；训练本身的损失和实际更新持续记录。原生每轮完整AP验证仍正常运行。

## 数据与比较口径

仍使用`pp_table_reannotated_v1`的114/40视频划分：训练17,281个已知框帧，验证5,101个已知框帧。训练117个、验证1,191个unknown帧均从原生检测训练/AP中排除，避免将未标注桌框当作无桌负例。图像不展开复制为另一套磁盘数据，运行目录保存实际帧清单、标签身份及代码哈希。

每轮遍历全量17,281个训练正样本并shuffle，末尾批次由原生训练器处理，Mosaic还会读取额外图像；原始训练薄框480帧，占2.78%，本次不加10%薄框配额。此前独立MLP每轮仅4,096次曝光、约10%薄框，因此本轮同时改变预训练、结构、输入分辨率、增强、曝光预算及选型指标，只能评价整套配方，不能单独归因YOLO结构或调色。

训练结束后自动载入主best，对全部6,292个验证帧推理，在5,101个已知框帧上计算帧均、视频均、629个薄框IoU、IoU≥0.5比例及视角/源组分桶；缺预测计0。另做全量训练集评分，保存逐帧预测、完整错误索引及每个含错误视频的最差叠图，并生成与两版B＋MLP、独立MLP＋调色的对照表。原生mAP与上述单主框IoU不同，不能直接横向比较。
